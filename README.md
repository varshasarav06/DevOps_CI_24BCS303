# DevOps CI - Grade Calculator

## Project Description

This project is a simple Grade Calculator application developed as part of the DevOps Mastery assignment.

The application accepts a student's mark and calculates the corresponding grade.

## Grade Criteria

- 90 to 100: A
- 80 to 89: B
- 70 to 79: C
- 60 to 69: D
- Below 60: F
- Marks outside the range 0 to 100: Invalid

## Project Structure

- src/ - Contains the application source code.
- tests/ - Contains the test files.
- README.md - Contains project documentation.
- .gitignore - Specifies files that should not be tracked by Git.

## How to Run the Application

python src/grade_calculator.py

## How to Run the Tests

python -m unittest discover -s tests
